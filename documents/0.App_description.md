# TacoLearn - Application Overview

## Project Vision

**TacoLearn** is an **Adaptive Japanese Learning Platform** designed specifically for **JLPT (Japanese Language Proficiency Test)** preparation.

### One-line Definition
> **TacoLearn — Your Personal JLPT Coach**

> **Taco Learn là nền tảng học tiếng Nhật thích ứng, biến dữ liệu luyện JLPT thành kế hoạch học tập cá nhân hóa mỗi ngày.**

---

## Core Concept

### The Problem
Current Japanese learning platforms are fragmented:
- Learning in class → Practice tests → Flashcards → Self-assessment
- No connection between these activities
- Learners don't know what to study next or why they're weak

### The Solution
TacoLearn connects all learning data to answer:
> **"Hôm nay tôi nên học gì để tiến gần hơn đến mục tiêu JLPT?"**

---

## Product Philosophy

### North Star Question
> **Does this feature help learners know what to study next and improve their efficiency?**

If **YES** → Prioritize  
If **NO** (just makes the system look complete) → Defer

### Learning Engine Focus
TacoLearn doesn't try to have the most content. TacoLearn aims to be excellent at:
> **Delivering the right content to the right person at the right time.**

---

## Core Differentiator: Adaptive JLPT Learning Loop

Unlike generic learning platforms, TacoLearn:

1. **Records everything**: Every question attempt, every mistake, every pattern
2. **Analyzes deeply**: Not just "right/wrong" but WHY the student failed
3. **Identifies weaknesses**: Granular skill mastery down to sub-skills
4. **Recommends intelligently**: Adaptive practice matching current weak areas
5. **Reinforces with timing**: Spaced Repetition at optimal intervals
6. **Measures improvement**: Tracks skill mastery over time
7. **Provides clear next steps**: Student always knows what to do next

## Learning Architecture

### Learning Data Flow
```
Student Practice
    ↓

Analyze Results
    ↓
Identify Weak Skills
    ↓
Generate Recommendations
    ↓

    ↓
Spaced Repetition Review
    ↓

    ↓
Recommend Next Action
```

## Key Features

### Phase 1: Learning Engine
- **Question Bank**: 10,000+ questions with metadata (level, skill, difficulty)
- **Attempt Tracking**: Records every student attempt with detailed metrics
- **Skill Mastery**: Calculates mastery % for each JLPT skill
- **Weakness Detection**: Identifies areas < 50%, 50-65%, 65-80% mastery
- **Adaptive Recommendations**: AI-powered practice suggestions
- **Daily Learning Plan**: Personalized daily study recommendations
- **Spaced Repetition System**: Optimal review intervals for long-term retention

### Phase 2: Learning Experience
- **Student Dashboard**: Central hub for today's learning and progress
- **Practice Interface**: Focused, engaging practice sessions
- **Result Analysis**: Detailed breakdown of performance and mistakes
- **Lesson Management**: Structured content (video, vocabulary, grammar, quiz)
- **Mock Tests**: Full JLPT exam simulations
- **Missed Class Catch-Up**: Automated recovery for absent students

### Phase 3: School Management
- **Student/Class Management**: Full student and class administration
- **Attendance System**: Attendance tracking and catch-up recommendations
- **Teacher Dashboard**: Class overview and student progress
- **Admin Dashboard**: School-wide analytics and reporting
- **Announcements**: School-wide communication system

## What TacoLearn is NOT

❌ Social networking platform  
❌ Chat between students  
❌ Livestream teaching  
❌ Video hosting (YouTube embeds only)  
❌ Marketplace for teachers  
❌ Generic LMS with too many features  
❌ AI chatbot as primary feature  

AI is used only to support:
- Explanation generation
- Personalized recommendations
- Learning plan creation
- Mistake analysis
