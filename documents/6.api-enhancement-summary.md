# API Enhancement Summary
## TacoLearn - RESTful API Specification Overview

---

## 1. API General Specifications

### Base URL
```
Development:  http://localhost:3001/api/v1
Production:   https://api.tacolearn.com/api/v1
```

### Authentication
- **Method**: JWT (JSON Web Tokens)
- **Header**: `Authorization: Bearer <token>`
- **Storage**: HttpOnly cookies
- **Refresh**: 7-day refresh token rotation

### Response Format (All Endpoints)
```json
{
  "status": "success|error",
  "data": {},
  "message": "Human readable message",
  "timestamp": "2026-01-15T10:30:00Z",
  "meta": {
    "page": 1,
    "limit": 20,
    "total": 100
  }
}
```

### Error Handling
```json
{
  "status": "error",
  "message": "Validation failed",
  "errors": [
    {
      "field": "email",
      "message": "Invalid email format"
    }
  ],
  "timestamp": "2026-01-15T10:30:00Z"
}
```

### HTTP Status Codes
- `200 OK` - Successful GET/PUT/PATCH
- `201 CREATED` - Resource created
- `204 NO CONTENT` - Successful DELETE
- `400 BAD REQUEST` - Validation error
- `401 UNAUTHORIZED` - Missing/invalid token
- `403 FORBIDDEN` - Insufficient permissions
- `404 NOT FOUND` - Resource not found
- `409 CONFLICT` - Resource conflict
- `429 TOO MANY REQUESTS` - Rate limited
- `500 INTERNAL SERVER ERROR` - Server error

## 2. Authentication Endpoints

### Register
```
POST /auth/register
Content-Type: application/json

{
  "email": "student@example.com",
  "password": "SecurePass123!",
  "full_name": "Tanaka Taro",
  "role": "STUDENT"
}

Response (201):
{
  "status": "success",
  "data": {
    "id": "uuid",
    "email": "student@example.com",
    "full_name": "Tanaka Taro",
    "role": "STUDENT"
  },
  "message": "User registered successfully"
}
```

### Login
```
POST /auth/login
Content-Type: application/json

{
  "email": "student@example.com",
  "password": "SecurePass123!"
}

Response (200):
{
  "status": "success",
  "data": {
    "accessToken": "jwt_token_here",
    "refreshToken": "refresh_token_here",
    "user": {
      "id": "uuid",
      "email": "student@example.com",
      "role": "STUDENT"
    }
  }
}
```

## 4. Practice Endpoints

### Create Practice Session
```
POST /practice/session
Authorization: Bearer <token>
Content-Type: application/json

{
  "type": "ADAPTIVE",  // or TARGETED, MIXED, WEAK_AREAS
  "level": "N2",
  "skill": "Reading.AuthorOpinion",  // optional for ADAPTIVE
  "questionCount": 10
}

Response (201):
{
  "status": "success",
  "data": {
    "sessionId": "uuid",
    "questions": [
      {
        "id": "q_uuid",
        "content": "...",
        "choices": [...],
        "number": 1,
        "totalQuestions": 10
      }
    ]
  }
}
```

### Submit Answer
```
POST /practice/session/{sessionId}/answer
Authorization: Bearer <token>
Content-Type: application/json

{
  "questionId": "q_uuid",
  "answer": "C",
  "timeSpent": 45
}

Response (200):
{
  "status": "success",
  "data": {
    "questionNumber": 1,
    "totalQuestions": 10,
    "nextQuestion": { ... }  // or null if last question
  }
}
```

### Get Practice Results

## 8. Rate Limiting

All endpoints rate limited:
- **Public endpoints**: 100 requests / 15 minutes per IP
- **Authenticated endpoints**: 1000 requests / 15 minutes per user

Headers returned:
```
X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 999
X-RateLimit-Reset: 1234567890
```
