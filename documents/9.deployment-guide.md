# 🚀 Deployment Guide - TacoLearn Platform

## Overview

TacoLearn is a full-stack monorepo with:
- **Backend**: NestJS API (Port 3001)
- **Frontend**: Next.js 16 App Router (Port 3000)
- **Database**: PostgreSQL
- **Cache**: Redis (optional, for session/caching)

---

## Prerequisites

- Node.js 18+ and pnpm 8+
- Docker & Docker Compose
- PostgreSQL 14+
- Git

---

## 📋 Development Setup

### 1. Clone and Install

```bash
git clone <repository-url>
cd tacolearn
pnpm install
```

### 2. Environment Configuration

Create `.env.local` files:

#### Backend (`backend/.env.local`)
```env
# Database
DATABASE_URL=postgresql://user:password@localhost:5432/tacolearn

# JWT
JWT_SECRET=your-super-secret-jwt-key-min-32-chars
JWT_EXPIRATION=86400

# Server
NODE_ENV=development
PORT=3001

# CORS
CORS_ORIGIN=http://localhost:3000

# Optional: Redis
REDIS_URL=redis://localhost:6379
```

#### Frontend (`frontend/.env.local`)
```env
NEXT_PUBLIC_API_URL=http://localhost:3001/api/v1
NEXT_PUBLIC_APP_NAME=TacoLearn
```

### 3. Database Setup

```bash
# Generate Prisma client
cd backend
pnpm prisma generate

# Run migrations
pnpm prisma migrate dev

# Seed initial data
pnpm prisma db seed
```

### 4. Start Development Servers

```bash
# Terminal 1: Backend
cd backend
pnpm start:dev

# Terminal 2: Frontend
cd frontend
pnpm dev

# Terminal 3: Prisma Studio (optional)
cd backend
pnpm prisma studio
```

Access:
- Frontend: `http://localhost:3000`
- Backend API: `http://localhost:3001/api/v1`
- Swagger Docs: `http://localhost:3001/docs`

## 🐳 Docker Deployment

### Build and Run Locally

```bash
# Build images
docker-compose build

# Start services
docker-compose up -d

# Check logs
docker-compose logs -f
```

This starts:
- PostgreSQL on `localhost:5432`
- Backend API on `localhost:3001`
- Frontend on `localhost:3000`

### Docker Compose File Structure

```yaml
version: '3.8'

services:
  postgres:
    image: postgres:15-alpine
    environment:
      POSTGRES_DB: tacolearn
      POSTGRES_USER: tacouser
      POSTGRES_PASSWORD: tacopass
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

  backend:
    build:
      context: .
      dockerfile: backend/Dockerfile
    ports:
      - "3001:3001"
    environment:
      DATABASE_URL: postgresql://tacouser:tacopass@postgres:5432/tacolearn
      JWT_SECRET: dev-secret-key
      NODE_ENV: development
    depends_on:
      - postgres

  frontend:
    build:
      context: .
      dockerfile: frontend/Dockerfile.prod
    ports:
      - "3000:3000"
    environment:
      NEXT_PUBLIC_API_URL: http://backend:3001/api/v1
    depends_on:
      - backend

volumes:
  postgres_data:
```

## 🌐 Production Deployment

### Strategy: Cloud Provider (AWS/GCP/Azure/Vercel)

#### Option 1: **Vercel (Recommended for Frontend)**

Vercel is ideal for Next.js hosting:

```bash
# Connect your Git repository to Vercel
# Vercel automatically deploys on push to main

# Environment variables in Vercel dashboard:
NEXT_PUBLIC_API_URL=https://api.tacolearn.com/api/v1
```

#### Option 2: **Railway/Render (Simple) for Backend**

Railway and Render support easy NestJS deployment:

```bash
# Add railway.json in project root
{
  "build": {
    "builder": "nixpacks",
    "config": {
      "nixpacks": {
        "pkgs": ["nodejs", "pnpm"]
      }
    }
  }
}

# Deploy: Push to GitHub, Railway auto-deploys
```

#### Option 3: **Docker on AWS ECS/GCP Cloud Run**

```bash
# Build and push to registry
docker build -t tacolearn-backend:latest -f backend/Dockerfile .
docker tag tacolearn-backend:latest gcr.io/PROJECT_ID/tacolearn-backend:latest
docker push gcr.io/PROJECT_ID/tacolearn-backend:latest

# Deploy to Cloud Run
gcloud run deploy tacolearn-backend \
  --image gcr.io/PROJECT_ID/tacolearn-backend:latest \
  --platform managed \
  --region us-central1 \
  --set-env-vars DATABASE_URL=postgresql://...
```

```env
NEXT_PUBLIC_APP_NAME=TacoLearn
```

## 📊 Database Migration

### Prisma Migrations

```bash
# Create a new migration (after schema change)
pnpm prisma migrate dev --name add_new_feature

# Run migrations
pnpm prisma migrate deploy

# Reset database (CAREFUL - deletes all data)
pnpm prisma migrate reset

# View migration status
pnpm prisma migrate status

# Check database schema
pnpm prisma studio
```

## 🔒 Security Checklist

### Pre-Deployment

- [ ] Set strong `JWT_SECRET` (min 32 chars, random)
- [ ] Use HTTPS in production (SSL certificate)
- [ ] Enable CORS only for trusted domains
- [ ] Set database password securely
- [ ] Enable database backups
- [ ] Use environment variables for all secrets
- [ ] Run security audit: `pnpm audit`
- [ ] Update all dependencies: `pnpm update`

### Post-Deployment

- [ ] Monitor error logs (Sentry/LogRocket)
- [ ] Set up database backups (daily)
- [ ] Monitor API performance (New Relic/DataDog)
- [ ] Enable rate limiting
- [ ] Set up HTTPS only
- [ ] Configure WAF (Web Application Firewall)
- [ ] Test login/auth flows
- [ ] Verify SRS recommendation engine works

## 📈 Scaling Considerations

### For Production Growth

1. **Database Optimization**
   ```sql
   -- Index frequently queried columns
   CREATE INDEX idx_question_attempts_student ON question_attempts(student_id, attempted_at);
   CREATE INDEX idx_skill_mastery_student ON skill_mastery(student_id, skill);
   ```

2. **Caching Layer (Redis)**
   - Cache student dashboard data
   - Cache skill mastery calculations
   - Cache SRS schedule

3. **Load Balancing**
   - Use nginx/HAProxy for multiple backend instances
   - Use CDN for frontend assets

4. **Database Replication**
   - Primary-replica setup for read optimization
   - Automatic failover

5. **Microservices (Future)**
   - Separate ML service for recommendations
   - Separate analytics service
   - Separate SRS scheduler

## 🚨 Troubleshooting

### Backend Won't Start

```bash
# Check logs
docker-compose logs backend

# Verify database connection
pnpm prisma db execute --stdin

# Check port 3001 is available
lsof -i :3001
```

### Frontend Shows API Errors

```bash
# Verify backend is running
curl http://localhost:3001/health

# Check CORS settings in backend
# Verify NEXT_PUBLIC_API_URL is correct
# Check browser console for errors
```

### Database Issues

```bash
# Backup data first
pg_dump $DATABASE_URL > backup.sql

# Reset (if necessary)
pnpm prisma migrate reset

# Verify schema
pnpm prisma db push

# Check migrations
pnpm prisma migrate status
```

## 🎯 CI/CD Pipeline (GitHub Actions)

Create `.github/workflows/deploy.yml`:

```yaml
name: Deploy TacoLearn

on:
  push:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: pnpm/action-setup@v2
      - uses: actions/setup-node@v3
        with:
          node-version: 18
          cache: 'pnpm'
      - run: pnpm install
      - run: pnpm lint
      - run: pnpm test

  build:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Build and push Docker images
        run: |
          docker build -t gcr.io/PROJECT_ID/tacolearn-backend:latest -f backend/Dockerfile .
          docker push gcr.io/PROJECT_ID/tacolearn-backend:latest

  deploy:
    needs: build
    runs-on: ubuntu-latest
    steps:
      - name: Deploy to Cloud Run
        run: |
          gcloud run deploy tacolearn-backend \
            --image gcr.io/PROJECT_ID/tacolearn-backend:latest
```
