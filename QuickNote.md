# Phase 1 - MVP North Star

## Goal

Enable JLPT learners to quickly start practicing, understand their mistakes, and know what to practice next.

## Core User Flow

Select JLPT Level / Exam
→ Start Practice
→ Answer Questions
→ View Results
→ Review Incorrect Answers
→ Continue Recommended Practice

## Scope

### 1. Authentication & Profile
- User registration and login.
- Basic profile management.
- JLPT target level and learning goal.

### 2. JLPT Practice
- Quickly select JLPT level and practice category.
- Start a practice session with minimal setup.
- Support core categories such as Vocabulary, Grammar, Reading, and Listening.
- Track answers and time spent.

### 3. Results & Incorrect Answer Review
- Show score, accuracy, and basic performance after each practice session.
- Allow users to review incorrect answers.
- Show correct answers and explanations.
- Identify basic weak areas based on incorrect answers.

### 4. Progress Tracking
- Track practice history.
- Track accuracy by JLPT level and category.
- Show recent learning progress.
- Track basic engagement metrics such as questions answered and study time.

### 5. Recommended Next Practice
- Recommend what the user should practice next based on recent performance and incorrect answers.
- Prioritize weak categories or recently missed question types.

## Success Criteria

A user can:

1. Open Taco Learn.
2. Quickly choose a JLPT practice set.
3. Start practicing with minimal friction.
4. Understand which answers were incorrect and why.
5. See their progress over time.
6. Know what to practice next.
```
Practice
→ Result
→ Review mistakes
→ Identify weakness
→ Recommend next practice
→ Practice again
```
